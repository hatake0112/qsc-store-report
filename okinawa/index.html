OKINAWA ・ 本島ドライブ

沖縄 家族旅 2泊3日

那覇空港でレンタカーを借りて、中部 → 北部 → 南部と本島をぐるっと回る旅程です。宿は恩納村に2連泊にして、子連れでも荷物の詰め直しを減らしています。

  • レンタカー
  • 宿：恩納村 2連泊
  • 総運転 約6〜7時間
  • 雨の日プランつき
1日目 那覇 → 北谷 → 恩納村 瀬長島・アメリカンビレッジ 2日目 恩納村 ⇄ 本部・今帰仁 美ら海水族館・古宇利島 3日目 恩納村 → 那覇空港 万座毛・国際通り
1日目

到着してゆっくり中部へ

宿泊：恩納村のリゾートホテル（2連泊）
  1. 10:30

    那覇空港 到着・レンタカー受け取り

    送迎バスで営業所へ移動します。混む日は手続きまで1時間ほどかかることもあります。

    子ども：6歳未満はチャイルドシートが必要です。予約時に年齢に合うもの（ベビー／チャイルド／ジュニア）を指定しておきます。
  2. 車 約15分
  3. 12:00

    瀬長島ウミカジテラスでランチ

    白い建物が並ぶ海沿いのテラス。飛行機の離着陸が間近に見えます。

    子ども：階段が多いのでベビーカーより抱っこひもが楽です。
  4. 車 約45分（国道58号は渋滞しやすい）
  5. 14:30

    北谷 アメリカンビレッジ

    観覧車のあるショッピングエリア。散策とおやつに。ブルーシールアイスはここで。

    子ども：すぐ隣のサンセットビーチは遊歩道があり、海を見ながら歩けます。
  6. 車 約40分
  7. 17:00

    恩納村のホテルにチェックイン

    夕日は西側の海に沈みます。夕食はホテルか近くの食堂で早めに。

2日目

美ら海水族館と古宇利島

宿泊：恩納村（同じホテル）
  1. 8:00

    ホテルを出発

    水族館は開館直後が空いています。朝食は早めに。

  2. 車 約1時間（許田ICから名護経由）
  3. 9:00

    沖縄美ら海水族館

    ジンベエザメが泳ぐ大水槽「黒潮の海」がいちばんの見どころ。所要2〜3時間。外の無料エリアでイルカショーも見られます。

    子ども：ベビーカー貸出あり。イルカショーの時間を入口で確認して、そこから逆算して回ると疲れにくいです。
  4. 12:00

    本部町で沖縄そばのランチ

    本部町は沖縄そばの店が多いエリア。人気店は昼前に並ぶので、11時半ごろの到着が目安です。

  5. 車 約30分
  6. 14:00

    古宇利大橋・古宇利島

    約2kmの橋を渡ると、両側が青い海のドライブに。橋のたもとの古宇利ビーチは遠浅で波も穏やかです。

    子ども：着替えとタオルを車に積んでおけば、波打ち際の水遊びがすぐできます。
  7. 車 約1時間
  8. 17:30

    ホテルに戻ってプール・夕食

    この日がいちばん運転の長い日。夜は移動なしでのんびり。

3日目

万座毛から那覇へ戻る

帰りの便：夕方発を想定
  1. 9:00

    万座毛

    象の鼻の形をした断崖。ホテルから10分ほどで、30〜40分あれば一周できます。

    子ども：崖の上は柵がありますが、手をつないで歩きましょう。
  2. 10:30

    チェックアウト

  3. 車 約1時間（沖縄自動車道 → 那覇IC）
  4. 12:00

    国際通りでランチとお土産

    タコライスや沖縄料理でランチ。お土産は紅いもタルト、ちんすこうなど。近くの牧志公設市場もおすすめ。

    子ども：通り沿いのコインパーキングは満車が多いので、少し離れた駐車場を先に決めておくと安心です。
  5. 車 約20分（給油してから）
  6. 15:00

    レンタカー返却 → 那覇空港

    満タン返しが基本。返却後に送迎バスで空港へ。出発の2時間前には返却しておくと安心です。

旅のメモ

雨の日の代わりの行き先

  • DMMかりゆし水族館（豊見城市・空港から車で約20分）
  • おきなわワールド 玉泉洞（南城市・鍾乳洞）
  • イオンモール沖縄ライカム（北中城村・中部）

運転のコツ

  • 那覇市内と国道58号は朝夕に混みます
  • 平日の朝夕はバス専用レーンの時間帯があります。標識を確認
  • 北部への移動は沖縄自動車道が速くて楽

子連れの持ち物（車に積むもの）

  • 着替え一式・タオル・ビーチサンダル
  • 日焼け止め・帽子（秋でも日差しが強い）
  • 車内用のおやつと飲み物

予約しておくもの

  • レンタカー＋チャイルドシート
  • 恩納村のホテル（2泊）
  • 美ら海水族館のチケット（事前購入で入口がスムーズ）
時刻と運転時間は目安です。営業時間・料金は出発前に各施設の公式サイトで確認してください。
